# Partner Logo Usage (Guidance)

- Use official, up-to-date assets provided by the partner.
- Prefer SVG; keep transparency and do not alter aspect ratio.
- Respect brand guides (clear space, color usage, minimum sizes).
- Use grayscale presentation by default; reveal color on hover.
- Link each logo to the partner’s official site or joint case study.
- Remove or replace placeholders promptly after obtaining permission.

File placement:
- Put approved logos under `public/assets/partners/` (or keep in `public/assets/logos/` if shared).
- Update `data/partners.ts` with { name, url, logo }.

Notes:
- If usage requires explicit permission, obtain approval before publishing.
- For sensitive or embargoed relationships, hide the logo and show text only.
